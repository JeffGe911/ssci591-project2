SSCI 591: Web GIS — Project 2  
Author: Yuqi Ge

## About

My Project 2 for SSCI 591. A map of the Monaco F1 circuit and seven places along the route.

- Live site: https://jeffge911.github.io/ssci591-project2/
- StoryMap: https://arcg.is/iSzfH
- Feature layer: https://services1.arcgis.com/ZIL9uO234SBBPGL7/arcgis/rest/services/Project_2_-_Monaco_Story_Locations/FeatureServer

## Language and tools
- HTML5 / CSS3 / JavaScript
- [Leaflet 1.9](https://leafletjs.com/) — interactive map
- [ArcGIS StoryMaps](https://storymaps.arcgis.com/) — the story
- Basemap tiles: [OpenStreetMap](https://www.openstreetmap.org/copyright)
- The layout and interactions come from what I learned building my own side projects.

## Data

- Route: [f1-circuits](https://github.com/bacinger/f1-circuits) by Tomislav Bacinger (MIT)
- Circuit reference: FIA circuit map, Monaco 2025, Document 18
- Seven stops: approximate, picked by me from the route
- Both layers use WGS 84 (EPSG:4326)
